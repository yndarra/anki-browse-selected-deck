## Browse Selected Deck

- `mode`:
  - `"changed"` *(default)*: when the browser is already open, **Browse** switches it to the selected deck only if a different deck was selected since last time. Otherwise your current search is kept.
  - `"always"`: every **Browse** click returns the browser to the selected deck.

---

- `mode`:
  - `"changed"` *(по умолчанию)*: если браузер уже открыт, «Обзор» переключает его на выбранную колоду, только если с прошлого раза выбрана другая. Иначе твой текущий поиск остаётся.
  - `"always"`: каждое нажатие «Обзор» возвращает браузер к выбранной колоде.
